\section{Higher-order goal}
The project aims to improve consumer digital rights and automated regulatory enforcement. While modern data privacy regulations (like GDPR and India's DPDP Act 2023) are comprehensive on paper, small businesses, open-source projects, and individual developers struggle to verify if their live applications actually comply. The engineering goal of \textbf{PrivaLens} is to translate complex data privacy guidelines into a verifiable, automated software auditing pipeline.

\section{Time-to-value}
\begin{itemize}[leftmargin=0.7cm]
    \item \textbf{Increment 1 (Week 4):} Establish a headless browser request interception shell to capture outgoing traffic and cookie events.
    \item \textbf{Increment 2 (Week 7):} Introduce an asynchronous job queue (Redis/Bull) to coordinate multi-page scans without causing server timeouts.
    \item \textbf{Increment 3 (Week 12):} Deploy a rule-based NLP parser classifying core privacy policy paragraphs and comparing them against runtime tracking tags.
    \item \textbf{Increment 4 (Week 15):} Deliver a unified Next.js dashboard containing detailed compliance scorecards and PDF audit reports.
\end{itemize}

\section{Problem Statement}
Modern web applications suffer from hidden, unconsented telemetry due to deep dependency trees and third-party script ingestion. Key challenges include:
\begin{itemize}[leftmargin=0.7cm]
    \item \textbf{PII Exfiltration:} Form inputs, cookies, and network request parameters leak personal identifiable information (PII) to ad servers.
    \item \textbf{Policy vs. Reality Mismatch:} Privacy policies claim ``no tracking'' or ``no data sharing,'' yet live network packets actively transmit tracking identifiers to external brokers.
    \item \textbf{High Cost of Compliance:} Hiring professional legal and compliance auditors is cost-prohibitive for startups and small-scale publishers.
    \item \textbf{Linter Limitations:} Static code analyzers fail to intercept dynamic script loading and runtime data transmissions.
\end{itemize}

\section{Proposed Solution}
We propose \textbf{PrivaLens}, an end-to-end compliance scanning service composed of:
\begin{itemize}[leftmargin=0.7cm]
    \item \textbf{Interactive Client Dashboard:} A Next.js portal where developers initiate crawls, monitor live traffic captures via WebSockets, and view compliance scores.
    \item \textbf{Headless Scraper & Queue:} A Node.js environment utilizing Puppeteer to crawl targets and monitor HTTP/WebSocket payloads. Jobs are orchestrated asynchronously using Redis and Bull.
    \item \textbf{Policy NLP Engine:} A Python service utilizing SpaCy/transformers to classify privacy clauses, compare them against runtime requests, and persist results in PostgreSQL.
\end{itemize}
